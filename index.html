what's inside

One app. Five tabs. No guessing.

Every card below is an actual tab in Lemonyde — this is the whole app, not a highlight reel.

Home

Install, update, launch — and run more than one

One-click install/update/uninstall for Sober with a live streaming log, plus isolated multi-instance slots so two accounts can run side by side without hitting Sober's single-instance lock.

FFlags

A FastFlag editor that respects the allowlist

Three ready-made presets, plus a library of flags confirmed to still be on Roblox's client-config allowlist. Nothing here is a flag that silently does nothing.

Customize

A cursor that actually looks right

Pick any image — Lemonyde resizes and centers it on the transparent 64×64 canvas Roblox expects, so it renders consistently instead of stretched or boxed in white.

Settings

The wrapper flags, in one place

use_opengl, enable_hidpi, close_on_leave, and touch_mode — the options Sober reads from the root of its own config, without opening a text editor.

Advanced

An escape hatch when something's stuck

Open the config, data, or instance folders directly, clear the asset overlay, or do a full FFlag/config reset — VinegarHQ's own documented recovery steps, one click away.

Built with

Rust, GTK4, libadwaita

A real native binary, not a wrapped web view — packaged as a plain install script or a single portable AppImage you can hand to a friend with no toolchain required.

know the limits

What Lemonyde won't pretend

FastFlags outside the allowlist do nothing

Since September 2025, Roblox enforces a strict allowlist for locally overridden FastFlags. Lemonyde only lists flags confirmed to still work — not a big list of flags that used to matter.

Multi-instance carries account risk

Roblox's rules treat running multiple clients at once as against policy, and community reports say it can trigger an anti-cheat flag. Lemonyde shows this warning in the app itself, not just in fine print here.

Font overrides are experimental

Unlike cursor overrides — which VinegarHQ's own docs confirm — Sober doesn't document the exact filename its Android-based client expects for a font. You may need to try a few names.

get it running

Install

Three ways in, depending on how much you want to touch a terminal.

Script (recommended)

Builds from source, checks for GTK4/libadwaita headers, and sets up a desktop entry.

git clone https://github.com/EpicNeco/Lemonyde
cd Lemonyde
chmod +x install.sh
./install.sh

Run without installing

For trying it out or hacking on the source directly.

cargo run --release

Portable AppImage

One file, no Rust or dev headers needed on the machine that runs it.

chmod +x build-appimage.sh
./build-appimage.sh
# → Lemonyde-x86_64.AppImage

Requires Flatpak with the Flathub remote to actually install/launch Sober — Lemonyde will tell you if it's missing rather than fail silently. Full requirements and build notes are in the README.
