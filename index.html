a native bootstrapper for Mocktail

Install, update, launch, edit FastFlags, and manage textures from one native GTK4 app.

features

  • Home — Install, update, launch, or uninstall Mocktail with isolated multi-instance slots
  • FFlags — Editor for flags confirmed to work on Roblox's allowlist with presets
  • Settings — Configure wrapper options through a clean GUI
  • Texture Overrides — Manage and import custom textures
  • Advanced — Access config/data folders, clear overlays, or reset everything
  • Native — Built with Rust, GTK4, and libadwaita. No webview.

info

FastFlags outside Roblox's allowlist do nothing — Lemonyde only lists ones confirmed to still work.
Running multiple instances is against Roblox's rules and can risk a flag on your account.

install

curl -fsSL https://epicneco.github.io/Lemonyde/install.sh | bash
