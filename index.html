Lemonyde

A native control panel for Mocktail

Install, update, launch, edit FastFlags, and manage textures from one native GTK4 app.

Get Lemonyde Build From Source

Features

Home

Install, update, launch, or uninstall Mocktail with isolated multi-instance slots.

FFlags

Edit flags confirmed to work on Roblox's allowlist with built-in presets.

Settings

Configure Mocktail wrapper options through a clean GUI.

Textures

Manage and import custom texture overrides.

Advanced

Access config/data folders, clear overlays, or reset everything.

Native

Built with Rust, GTK4, and libadwaita. No webview.

Info

Lemonyde is a free open source bootstrapper for Mocktail.

Not affiliated with Roblox Corporation or bigrat.space

FastFlags outside Roblox's allowlist do nothing — Lemonyde only lists ones confirmed to still work.

Running multiple instances is against Roblox's rules and can risk a flag on your account.
