Lemonyde
Features Discord GitHub

A native control panel for Sober, the VinegarHQ flatpak that runs Roblox on Linux.

Not affiliated with Roblox Corporation or VinegarHQ. Sober stays exactly as VinegarHQ ships it — Lemonyde only edits its config and calls flatpak on your behalf.

Get Lemonyde Build From Source

What it does

  • Home. Install, update, launch, or uninstall Sober, with isolated multi-instance slots for running more than one account.
  • FFlags. An editor for flags confirmed to still work on Roblox's allowlist, plus presets.
  • Customize. Set a cursor from any image — resized and centered to what Roblox expects, so it renders correctly.
  • Settings. The wrapper options Sober reads from its own config, without a text editor.
  • Advanced. Open the config/data folders, clear the asset overlay, or reset everything in one click.
  • Built with Rust, GTK4, and libadwaita. A native binary, not a wrapped web view.

What it won't pretend

  • FastFlags outside Roblox's allowlist do nothing — Lemonyde only lists ones confirmed to still work.
  • Running multiple instances at once is against Roblox's rules and can risk a flag on your account. Lemonyde warns about this in the app, not just here.
  • The font override is experimental — Sober documents the cursor format but not the exact filename it expects for a font.

Build From Source

git clone https://github.com/EpicNeco/Lemonyde
cd Lemonyde
chmod +x install.sh
./install.sh

Requires Flatpak with the Flathub remote to install/launch Sober — Lemonyde says so if it's missing. Prefer one portable file instead? Run ./build-appimage.sh. Full details in the README.
